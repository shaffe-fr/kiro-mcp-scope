# kmc spikes

Throwaway prototypes used to choose the TUI stack for kmc on Windows. Kept for
reference; not part of the tool.

- `spike-rust/` — ratatui + crossterm. The retained stack.
- `spike-go/` — Bubble Tea. `spike-go/diag/` is a standalone mouse-input
  diagnostic for Windows terminals.

Each directory has a `VERDICT.md` with the measurements and findings (in
French).
